# Clocktower Results

Хранение результатов игр Blood on the Clocktower: игры, голосования, сценарии, экспорт в Excel.

## Запуск

Двойной клик по `start.bat` — откроется http://localhost:3777.

Или вручную:

```
npm install
npm start
```

## Где что лежит

- `data/games.json` — все игры (создаётся при первом сохранении). Перед каждой записью предыдущая версия копируется в `data/games.backup.json`.
- `data/scripts.json` — сценарии (создаётся при первом изменении, резервная копия `data/scripts.backup.json`). Папка `data/` не хранится в git.
- `one-night-one-fight.json` — сценарий, с которого приложение начинает работу.
- `public/roles-data.js` — каталог всех ролей, `public/roles/*.png` — их иконки с wiki.bloodontheclocktower.com, а также перекрашенные варианты для сменивших сторону: `<id>_evil.png` (красные горожане и изгои) и `<id>_good.png` (синие приспешники и демоны). Всё создаётся скриптом `tools/fetch_roles.py`.
- `public/roles.js` — типы ролей и формат JSON сценариев.
- `server.js` — API и экспорт в Excel (`/api/export`).

## Обновление ролей

Когда на вики появятся новые роли:

```
python tools/fetch_roles.py
```

Нужны Pillow и numpy (`pip install pillow numpy`). Только перекрасить варианты заново: `python tools/fetch_roles.py --variants`.

## Сценарии

Раздел «Сценарии» — создание и изменение сценариев, импорт и экспорт JSON в формате официального Script Tool. В выборе роли при заполнении игры показываются только роли сценария этой игры. Роли ведущего (Fabled, Loric) можно добавить в сценарий, но игрокам они не выдаются.

## Экспорт в Excel

Кнопка «Экспорт в Excel» скачивает файл с листами:

- **Результаты** — одна строка на игрока в игре (игра, дата, ведущий, победа, игрок, роль, тип роли, команда, победил, сменил сторону, баллы, убит, сколько раз выставлялся, голосов всего, в каком голосовании заголосован). Удобно для сводных таблиц.
- **Голосования** — одна строка на выставленного игрока в каждом голосовании (номер голосования, игрок, роль, голосов, кто голосовал, заголосован).
- **Голоса** — одна строка на каждый голос: кто голосовал, его роль и команда, за кого, роль и команда выставленного.
- **Игры** — одна строка на игру: демон, число голосований, заголосованные с номером голосования.
- **Статистика игроков** — игры, победы, % побед, сумма и средний балл, отдельно за Добро и Зло, сколько раз заголосован и убит.
- **Статистика ролей** — сколько раз сыграна роль и % побед.

Команда игрока определяется по роли (Горожане/Изгои — Добро, Приспешники/Демон — Зло). Если ведущий отметил, что игрок сменил сторону (вкладка «Сменили сторону» при выборе роли), берётся новая сторона. У Путешественников сторона не определяется по роли: «Команда» и «Победил» остаются пустыми, а % побед считается без таких игр.
