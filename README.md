# Clocktower Results

Хранение результатов игр Blood on the Clocktower (сценарий ONE NIGHT ONE FIGHT).

## Запуск

Двойной клик по `start.bat` — откроется http://localhost:3777.

Или вручную:

```
npm install
npm start
```

## Где что лежит

- `data/games.json` — все игры (создаётся при первом сохранении). Перед каждой записью предыдущая версия копируется в `data/games.backup.json`.
- `public/roles.js` — список ролей сценария и их команды.
- `public/roles/*.png` — иконки ролей с wiki.bloodontheclocktower.com.
- `server.js` — API и экспорт в Excel (`/api/export`).

## Экспорт в Excel

Кнопка «Экспорт в Excel» скачивает файл с листами:

- **Результаты** — одна строка на игрока в игре (игра, дата, ведущий, победа, игрок, роль, тип роли, команда, победил, баллы). Удобно для сводных таблиц.
- **Игры** — одна строка на игру.
- **Статистика игроков** — игры, победы, % побед, сумма и средний балл, отдельно за Добро и Зло.
- **Статистика ролей** — сколько раз сыграна роль и % побед.

Команда игрока определяется по роли (Горожане/Изгои — Добро, Приспешники/Демон — Зло).
